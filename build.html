3 · The blueprint builder

Answer six questions. Get your first files.

Fill in the form (it starts with the example agent, so edit it into yours). On the right, agent.md, agent.toml, guardrails.toml and goal.md write themselves — copy or download them into my_agent/.

1Who is this agent?A name, and what it is for.
2The goalBecomes goal.md — the default task.
3The missionWho reads the result, and why.
4The phasesThe path the agent follows. Add 1 to 6.
5ToolsWhat it may use. Pick up to 4.

6Rules & safetyWhat it must never do, and when to hand over.


        

        
Then: save the four files into my_agent/ (replacing the examples), copy your input files into my_agent/workspace/, run python -m app doctor — and python -m app.
