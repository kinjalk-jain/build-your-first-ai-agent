1 · The starting line

Who starts the agent?

You do — with one command. No file in your project “calls” another. The only program that runs is the engine in app/; your markdown files are text it reads.

❌ A common guess
agent.mdcallsskillscalltools

“agent.md is the main file that runs the others.” It feels natural — but a markdown file can't run anything.

✅ What really happens
python -m appreadsagent.md + skills→the modelaskstools

The program starts, reads your files as text, and lets the model ask for tools. The program runs them.

✓ You now know…

  • You start the agent with python -m app. agent.md is read as text — it calls nothing.
  • Your goal comes from the command, --goal-file, goal.md, or the web page / URL. Your key lives in .env and only the model client uses it.
  • A “tool call” is the model asking; the loop checks the rules, the tool hub forwards it, and a plain Python function does the real work.
