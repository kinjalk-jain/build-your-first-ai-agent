The questions people actually ask

        
Short answers, then a way to see them.

      

      

        1
Which file is the “main” one — and does agent.md call the others?Spoiler: it doesn't. See who starts the agent and how your files become one prompt.

        2
How do I run it end to end — where do the key and my prompt go?The key lives in .env. The goal can come from four places. Pick yours.

        3
When I press Enter, what happens, in what order?A recorded run you can play, pause and scrub — with every file lighting up as it works.

        4
When the agent “calls a tool”, what really happens?Like shifting gears: the driver asks, the gearbox does. Try breaking it to see the guardrails react.
