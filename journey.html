1 · The difference

Same question. Two very different answers.

Ask both: “Brief me on the files in this folder.” Press the buttons and watch.

🧑 “Brief me on the files in this folder.”
🎯

A goal

Not a question to answer — an outcome to reach: “brief me”, “find the risks”, “fix the failing test”.

🧰

Tools

It can do things: list files, read them, search, write a report. Each tool returns real output, never a guess.

🔁

A loop

Look → decide → act → look again. It stops when it believes the goal is met — and tells you what it did.

5 · Your part

So what do you write?

Less than you'd fear. The loop, the tool plumbing, the safety net and the recording are already built. You write the parts that are specific to your problem — mostly in plain English.

✅ Already built for you

  • The loop — ask, run tools, repeat, know when to stop
  • Tool calling & chaining — results feed the next choice
  • Parallel tool calls — independent tools run together
  • Rate limits & retries — it waits and carries on
  • Guardrails engine — blocks, asks a human, blanks out secrets
  • Recording — every run saved, even a crash
